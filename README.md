### FundPilot AI
*Multi-Agent AI Fund Analytics Platform*

![Spring Boot](https://img.shields.io/badge/Spring_Boot-6C63FF?style=flat-square&logo=springboot&logoColor=white)
![Vue 3](https://img.shields.io/badge/Vue_3-6C63FF?style=flat-square&logo=vuedotjs&logoColor=white)
![Spring AI](https://img.shields.io/badge/Spring_AI-6C63FF?style=flat-square&logo=spring&logoColor=white)
![DashScope](https://img.shields.io/badge/DashScope-6C63FF?style=flat-square&logo=alibabacloud&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-6C63FF?style=flat-square&logo=mysql&logoColor=white)
![Redis](https://img.shields.io/badge/Redis-6C63FF?style=flat-square&logo=redis&logoColor=white)

</div>

FundPilot AI is a multi-agent platform that makes fund research and investment decisions smarter. Users can search funds, chat with an AI advisor, manage portfolios, and receive automated analysis reports — all powered by a coordinated agent system under the hood.

| Feature | Description |
|---|---|
| 🔍 Intelligent Fund Search | Query and filter funds with natural language |
| 🤖 AI Investment Assistant | Conversational advisor powered by LLM |
| 📁 Portfolio Management | Track and manage personal fund holdings |
| 📊 Automated Analysis Reports | AI-generated fund research reports |
| 🕸️ Multi-Agent Architecture | Coordinated agents for complex analytics tasks |
